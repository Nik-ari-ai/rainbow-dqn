Rainbow объединяет шесть компонентов: Double DQN, Prioritized Experience Replay, Dueling Networks, multi-step returns, distributional RL (C51), Noisy Networks. При выборе реализации проверяем наличие всех шести.

## Как начать

Можно открыть `notebooks/rainbow_dqn.ipynb` через **File → Open notebook → Upload** в [Google Colab](https://colab.research.google.com/).

Для локальной работы из папки репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab notebooks/rainbow_dqn.ipynb
```

В Windows вместо `source` используйте `.venv\Scripts\activate`. Зависимости для обучения и версии пакетов участник 2 добавит после выбора реализации; текущий список нужен только для работы с notebook.

Каждый работает в своей ветке (`algorithm`, `implementation`, `environment`) и открывает pull request в `main`. Перед изменением общего notebook согласуем разделы; перед коммитом очищаем вывод ячеек.
